# process-animator

Animated storytelling viewer for regulated process state machines.
Reads process ontology (TTL) and renders step-by-step narratives
with actors, transactions, chain state, and deadline countdowns.

PureScript + Halogen. Embeddable via iframe.

## Development

```bash
nix develop
just build
```
